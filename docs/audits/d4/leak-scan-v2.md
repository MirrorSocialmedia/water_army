## 判定彙總（新洩漏 R40–R52）
**新洩漏入賬 14 條（R40–R53；全部附讀值證據）**：高 = R48／R46／R40／R42／R41；中–高 = R45／R43；中 = R44／R49／R50；低–中 = R47／R51／R52；低（延伸 KL）= R53。最高 severity（高）＝：
1. **R48 sensor 零事件（web）** — 0 sensor × 0 event × 兩台載體；FB／Google 反 bot 直接面。
2. **R46 connection.type=ethernet ＋ pointer media 全假**（同 maxTouchPoints 矛盾）— 兩台一樣。
3. **R40 ABI=x86_64／abilist x86 掛頭 ＋ ndk_translation bridge** × ARM-only 機型 — 結構性、app+GMS+web 三面可達。
4. **R42 noril=yes 無電台形態**（＋telephony feature 冇＋subscription service 死）。
5. **R41 navigator.platform 分歧**（gm WebView `Linux i686` vs fb Chrome `Linux armv81`）— 同一部機兩個答案。

**正面讀值（clean，唔入賬）**：serialno 逐機獨一、fingerprint 零容器字面痕、android_id 逐機獨一、TZ prop↔web 一致、screen 幾何主流＋逐機差異、UA-CH 未注入態一致、fb dev-state 三項 clean（dev settings／wifi adb／tcp port）、無 qemu／Magisk 痕、WebView 版本故事對得上（R38 正面鏈延伸）。

**口徑**：本次全部讀值即證據；severity = 封號語境（FB／Google 風險引擎可讀性 × 消費機常態偏離度），唔係「有冇修」。
